# The Artifact is data interpreted by one engine, not generated code

An Artifact could be compiled into a runnable Playwright script per capability, which the brief even lists as a stretch goal. We instead execute the Artifact directly with a single Replay Engine over a closed action and predicate vocabulary, because every safety guarantee — policy layering, the risk gate, retry budgets, the redaction chokepoint, the write-ahead log, "no LLM at replay" — then lives in one place that no Artifact can express its way around, and a fix reaches every capability at once. Generated scripts would carry their own copies of those checks and drift apart. This also matches PreAct, which executes its state machine directly rather than regenerating a flat script. Code generation remains available as a read-only `export` for reviewers.
