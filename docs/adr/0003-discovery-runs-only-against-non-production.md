# Discovery runs only against non-production environments

A Discovery Run has an LLM proposing actions on an unfamiliar app, and every turn sends screen content to a model provider. Both risks disappear against a tenant's UAT or training environment with synthetic members, so the environment tag is enforced in code: discovery refuses to start against an origin marked production. AgentRR names the same pattern ("Untrusted Model Record, Trusted Model Replay"). The cost is that test environments differ from production, so the first production replays may hit Unknown States; those escalate or fail safely and feed the review loop. Because banks routinely refresh test environments from production, observation text is redacted on the outbound path as well, and screenshots are cropped and downscaled — a partial control, honestly stated.
